# LLM Code Medic

One-click AI code repair for Python projects.

## Features

* Automatic bug diagnosis
* Root cause analysis
* AI-generated patches
* Multi-file repair
* AST-aware code understanding

## Usage

1. Start LLM Code Medic backend

```bash
uvicorn server.app:app --reload
```

2. Open your project in VS Code

3. Run:

```
LLM Code Medic: One Click Fix
```

4. Paste traceback or error message

5. Wait for repair result

## Requirements

Backend API must be running on:

```
http://127.0.0.1:8000
```
